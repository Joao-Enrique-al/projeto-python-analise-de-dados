# 🐍 Projetos Python — Automação, Dados e Inteligência Artificial

Repositório desenvolvido durante meus estudos e projetos práticos com Python, reunindo aplicações voltadas para automação, análise de dados, inteligência artificial e desenvolvimento de sistemas web.

O objetivo deste repositório é documentar minha evolução prática utilizando Python e suas principais bibliotecas e ferramentas.

---

## 🚀 Projetos

### 1. 🤖 Criação de Bot

Projeto desenvolvido para praticar automação de tarefas utilizando Python.

**Conceitos trabalhados:**

- Automação de tarefas
- Manipulação de arquivos
- Interação com aplicações
- Python
- Automação de processos

📁 Pasta: `1 - Criacao de bot`

---

### 2. 📊 Análise de Dados e Criação de Tabela

Projeto focado no tratamento, organização e análise de dados utilizando Python.

**Tecnologias utilizadas:**

- Python
- Pandas
- Manipulação de dados
- Análise exploratória
- Criação e organização de tabelas

📁 Pasta: `2 - Analise de dados e criacao de tabela`

### 3. 🤖 Agente de IA

Aplicação desenvolvida para explorar a integração entre Python e Inteligência Artificial.

- Inteligência Artificial

### 4. 📈 Sistema de Gestão de Vendas

Sistema web desenvolvido com Python e Streamlit para cadastro, visualização e análise de vendas.

O sistema permite cadastrar vendas e visualizar indicadores através de um dashboard.

**Funcionalidades:**

- Cadastro de vendas
- Registro de vendedor
- Registro de produto
- Controle de quantidade
- Controle de valores
- Visualização das vendas
- Cálculo de faturamento
- Cálculo de ticket médio
- Dashboard
- Gráficos de vendas
- Análise por vendedor
- Análise por produto

**Tecnologias utilizadas:**

- Python
- Streamlit
- Pandas
- Plotly
- CSV

🌐 Aplicação online:

https://gestao-nmgpvh8fuh2qosytzgfnac.streamlit.app/

📁 Pasta: `4 - Sistema de gestão online`
